# Dos libre

Routine du matin de 15 minutes, sans matériel, pour relâcher les tensions du dos (mobilité, renforcement, étirements), avec un onglet de conseils pour le petit-déjeuner.

Appli web installable : ouvrir https://c2kgyvg6f8-lab.github.io/dos_libre/ dans Safari, puis Partager → « Sur l'écran d'accueil ».
